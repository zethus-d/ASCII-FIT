# ASCII//FIT APK
1. Is folder ka sab kuch (hidden .github folder samet) ek NAYI GitHub repo mein upload/push karo.
2. Actions tab -> "Build APK" chalega (ya Run workflow dabao).
3. 4-6 min baad Releases page se `ascii-fit.apk` phone pe download karo.
4. App ke neeche-left corner mein BUILD stamp dikhega, usse pata chalega ki naya version hai.
Naya version: www/index.html replace karke commit karo. Keystore wahi rehta hai, to update purane app ke upar install ho jayega.
